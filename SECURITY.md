# Security policy

TierGuard is research simulation software, not a production security control.
The confirmatory implementation requires trusted edge aggregators to inspect
individual client updates. It does not provide secure aggregation, update
confidentiality, malicious-edge protection, authenticated transport, rollback
protection, or deployment hardening.

Please report suspected code-execution, dependency, or data-handling
vulnerabilities through GitHub's private vulnerability-reporting interface for
this repository. Do not include credentials, personal data, or unpublished
participant data in an issue.
